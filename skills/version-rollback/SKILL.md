# 자동 원복 및 버전 관리 스킬 (Version Rollback Skill)
본 스킬은 AI가 수행한 비정상적인 코드 수정이나 의도하지 않은 빌드 에러를 감지했을 때, 즉각 이전의 안정적인 코드 상태로 되돌리기 위한 스킬 가이드입니다.

## 원복 전략
- **자동 Git Commit 수행**: 주요 기능 구현 및 파일 수정 전에 임시 커밋 혹은 스테이징을 수행하도록 유도합니다.
- **체크포인트 복구 커맨드**:
  ```bash
  # 변경 사항 전체 리셋
  git reset --hard HEAD
  # 특정 파일만 이전 상태로 복구
  git checkout HEAD -- <file_path>
  ```
- **에러 감지 및 자동 롤백**: 로컬 프로토타입 실행 중 빌드 실패(`npm run build` 실패) 또는 런타임 에러가 다수 검출되는 경우, 자동으로 이전의 정상 태그(Tag)나 커밋으로 하드 리셋을 proposing 하는 가이드라인을 제공합니다.
