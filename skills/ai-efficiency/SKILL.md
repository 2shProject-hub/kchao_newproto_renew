# AI 효율성 극대화 스킬 (AI Efficiency Skill)
본 스킬은 Antigravity, Claude Code, Codex 등의 AI 에이전트가 컨텍스트 토큰을 절약하고 빠르고 정확하게 소스코드를 수정 및 검증할 수 있도록 돕는 행동 가이드라인입니다.

## AI 가이드라인
- **작업 범위 엄격 제한**: 요청한 범위에 해당되는 부분만 정확하게 신규 구성, 수정 구성, 삭제 등을 수행해야 하며, 변경 요청을 받지 않은 무관한 소스코드 영역에 대한 임의 변경작업은 일절 진행하지 않습니다.
- **최소 단위 수정 권장**: 파일 전체를 덮어쓰기(`write_to_file` Overwrite)하기보다 변경이 필요한 contiguous block 또는 non-contiguous chunks만 정확히 지정하여 수정하는 `replace_file_content` 또는 `multi_replace_file_content` 도구를 우선 사용합니다.
- **컨텍스트 축소**: 대규모 디렉토리 검사 시 전체 파일을 다 읽기보다 `grep_search`를 사용하여 필요한 파일만 타겟팅해 탐색을 수행합니다.
- **단계별 실행**: 복잡한 비즈니스 로직 작성 시 전체를 한 번에 구현하지 않고 핵심 유틸리티 -> 컴포넌트 -> 대시보드 순으로 점진적으로 구현하여 테스트를 병행합니다.
