# 한국어 학습앱 리뉴얼 에이전트 및 Skill 구성 보고서 v1.1

베트남 현지인을 대상으로 하는 한국어 학습 앱의 리뉴얼을 가속화하고 AI 협업 효율성을 극대화하기 위한 에이전트 및 Skill 구성 전략을 기술합니다.

- **목적**: 기획, 디자인, 개발을 유기적으로 연결하고, 로컬 웹 환경에서 즉시 확인 및 수정할 수 있는 프로토타입 템플릿 제공.
- **추가 구현 사양**:
  - **AI 협업 스킬 (`ai-efficiency`)**: AI가 코드를 생성하고 작업하는 과정의 효율성을 극대화하기 위한 프롬프트 가이드.
  - **원복 스킬 (`version-rollback`)**: 작업물 적용 과정에서 문제가 생길 경우 이전 안정 버전으로 신속히 복원(Rollback)하는 환경 및 방법 정의.
  - **개발 소스 분석 스킬 (`source-analyzer`)**: 기존 React Native 소스 또는 다른 리퍼런스 코드에서 UI 디자인과 비즈니스 로직을 추출해 내는 분석용 프롬프트 및 프로세스.
