# 한국어 학습앱 리뉴얼 에이전트 및 Skill 구성 보고서 v2.0

베트남 현지인을 대상으로 하는 한국어 학습 앱의 리뉴얼을 가속화하고 AI 협업 효율성을 극대화하기 위한 에이전트 및 Skill 구성 전략을 기술합니다.

- **목적**: 기획, 디자인, 개발을 유기적으로 연결하고, 로컬 웹 환경에서 즉시 확인 및 수정할 수 있는 프로토타입 템플릿 제공.
- **대시보드 전체 디자인 통일화**:
  - **K-Chao 원본 테마 완벽 동기화**: `C:\dev\kchao-lesson1-main`의 `src/index.css`를 기반으로 에뮬레이터 내부에 국한되던 디자인 코드를 대시보드 시스템(좌측 사이드바, 우측 정보 패널, 버튼 그룹, 폰트, 구분선, 입체 섀도우) 전체로 확대 적용했습니다.
  - **세부 스타일 통일**:
    - 대시보드 전체 배경: `#eef3f3`
    - 사이드바 및 가이드 배경: `#ffffff`
    - 보더(경계선): `#dce5e7`
    - 대시보드 제목 좌측에 브랜드 인디케이터 바 추가.
    - 폰트 스택 두께(Pretendard 및 Noto Sans KR 800/850) 적용.
- **신규 학습 미션 (`mission`) 액티비티 추가**:
  - **기능 설계**: 차시 시작 시 미션과 주요 목표를 명확하게 숙지시키는 신규 액티비티 화면을 구성했습니다.
  - **세부 컴포넌트**:
    - **1~6차시 동적 배지**: 우측 개발 참고 탭에 연동된 차시 제어 셀렉터 변경에 따라 '1차시 학습 미션' ~ '6차시 학습 미션'으로 실시간 갱신 처리했습니다.
    - **텍스트 한도 정의**: 본문 미션 타이틀 텍스트가 최대 2줄(line-clamp-2)로 엄격 제한되어 레이아웃이 깨지지 않도록 구현했습니다.
    - **블릿(Bullet) 표시 목록**: N개의 상세 서브 타이틀 목록을 원문 그대로 불릿 표시(`•`)와 매핑하여 렌더링되게 했습니다.
    - **교실 그래픽 배너**: Teal 톤 테마가 조화된 벡터 일러스트 목업 레이아웃을 중앙 영역에 배치하였습니다.
  - **다국어 대응**: 한국어(KR) / 베트남어(VT) 탭과 다국어 셀렉터 변경에 유기적으로 부합하도록 현지화 텍스트 리소스를 매핑했습니다.
- **AI 협업 및 작업 한정 규칙 추가**:
  - **작업 범위 제약 조건 명시 (`skills/ai-efficiency/SKILL.md`)**: AI가 코드 작업을 수행할 때 반드시 요청 범위 내에 해당하는 항목만 작업하도록 역할을 제한합니다.
- **레이아웃 구조**:
  - **좌측 영역**: Anydevice 에뮬레이터 설정 및 화면 선택용 콤보박스(Combo Box) 구성.
  - **중앙 영역**: 디바이스 크기(AOS/iOS)가 에뮬레이터 값에 맞추어 동적으로 변하는 미리보기 뷰 배치.
  - **우측 영역**: 화면 설명, 개발 참고, 디자인 참고 3개의 상세 영역으로 구성.
